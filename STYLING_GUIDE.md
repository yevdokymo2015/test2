# Путівник по стилізації книги А5

## Що було зроблено

### 1. Списки (БЕЗ крапок!)
- **Enumerate**: використовується формат `1)` замість `1.`
- **Itemize**: використовується дефіс `--` замість крапки `•`

```latex
\begin{enumerate}
    \item Перший пункт   % → 1) Перший пункт
    \item Другий пункт   % → 2) Другий пункт
\end{enumerate}

\begin{itemize}
    \item Маркер один    % → -- Маркер один
    \item Маркер два     % → -- Маркер два
\end{itemize}
```

### 2. Професійні команди виділення тексту

#### Для ключових термінів (жирний)
```latex
\term{важливий термін}
```
Приклад: **важливий термін**

#### Для особливо важливих понять (жирний курсив)
```latex
\important{критичне поняття}
```
Приклад: ***критичне поняття***

#### Для прикладів та іноземних термінів (курсив)
```latex
\example{приклад або foreign term}
```
Приклад: *приклад або foreign term*

#### Для акценту на ключових словах
```latex
\keyword{ключове слово}
```
Приклад: *ключове слово* (emph)

#### Для визначень понять (жирний курсив)
```latex
\defterm{поняття що визначається}
```
Приклад: ***поняття що визначається***

#### Центроване виділення
```latex
\centered{Текст по центру}
```

#### Жирний заголовок параграфа без нумерації
```latex
\parheading{Назва підрозділу} Текст далі йде відразу...
```
Результат: **Назва підрозділу.** Текст далі йде відразу...

### 3. Оформлення розділів

#### Chapter (Розділи)
- Великі жирні ВЕРХНІМ РЕГІСТРОМ
- По центру
- Розмір: `\Large`

#### Section (Підрозділи)
- Жирний шрифт
- Розмір: `\large`
- **БЕЗ крапки** після номера (1.1 а не 1.1.)

#### Subsection (Підпідрозділи)
- Жирний шрифт
- Розмір: `\normalsize`
- **БЕЗ крапки** після номера

#### Subsubsection (Додаткові підрозділи)
- Жирний курсив
- Розмір: `\normalsize`

#### Paragraph (Міні-заголовки)
- Жирний шрифт вбудований в текст
- З крапкою в кінці

### 4. А5 Геометрія сторінки

Поля оптимізовані для А5 з палітуркою:
- **Ліве поле (внутрішнє)**: 20mm
- **Праве поле (зовнішнє)**: 15mm
- **Верхнє поле**: 15mm
- **Нижнє поле**: 15mm
- **Відступ для палітурки**: 5mm

Міжрядковий інтервал: 1.15 (оптимально для А5)

### 5. Шрифти

- **Основний текст**: Times (через mathptmx)
- **Моноширинний**: Courier
- Розмір базовий: 11pt (оптимально для А5)

## Як використовувати у своїх файлах

Просто використовуйте команди там, де потрібно виділити текст:

```latex
Наприклад, \term{фішинг} — це \defterm{метод соціальної інженерії}, 
який використовує \keyword{обман} для крадіжки даних. 
\example{Приклад}: шахраї надсилають \important{фальшиві листи}.

\parheading{Захист від фішингу} Використовуйте:
\begin{enumerate}
    \item Двофакторну автентифікацію
    \item Перевірку URL-адрес
\end{enumerate}
```

## Рекомендації

1. **Не зловживайте виділенням** - надто багато жирного/курсивного тексту втрачає ефект
2. **Використовуйте `\term{}` для термінів**, що вперше з'являються
3. **`\important{}`** - тільки для критично важливої інформації
4. **`\parheading{}`** - для неофіційних підзаголовків всередині розділів
